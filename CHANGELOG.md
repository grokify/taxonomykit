## [v0.1.0] - 2026-10-14 ([`2ded4c1`](https://github.com/grokify/taxonomykit/commit/2ded4c1))

### Highlights

- A validated, immutable taxonomy tree with polyhierarchy, deterministic ordering and per-language labels, built from a flat node list or a CSV/TSV/PSV/JSON file, with a CLI to validate, convert and print it.

### Added

- `Tree` built by `Build` from `[]Node`: multiple parents per node with `Parents[0]` as the primary parent; deterministic sibling ordering (explicit `Order`, then default-language name, then id; `WithOrderBy(OrderByID)` to skip names); navigation via `Roots`, `Parent`, `Parents`, `Children`, `Siblings`, `Lineage`, `Lineages`, `Descendants`, `Leaves`, `IsLeaf`, `Depth`, `LCA`, `Walk`, `WalkFrom` and the `All` iterator; `Document` to export the nodes back ([`81a61eb`](https://github.com/grokify/taxonomykit/commit/81a61eb))
- `Validate` reporting every structural problem with a stable code (`id.invalid`, `id.duplicate`, `parent.missing`, `parent.self`, `parent.duplicate`, `cycle`, `root.none`, `label.default.missing`, `slug.duplicate`, `lang.invalid`); `Build` returns the first; `WithSlugScope(SlugScopeSiblings)` for path-style URLs ([`81a61eb`](https://github.com/grokify/taxonomykit/commit/81a61eb))
- Localization: `NormalizeLang` for BCP-47 tags, `FallbackChain` (exact tag → shorter prefixes → default language), `Label`, `Name`, `Slug`, `Breadcrumb` recording the language each crumb resolved to, and `BySlug` over effective slugs where explicit slugs win over fallbacks ([`81a61eb`](https://github.com/grokify/taxonomykit/commit/81a61eb))
- `flat` codec: read CSV, TSV and PSV with a header row or a `Columns` mapping, `#` comments and blank lines, one row per node and language, extra columns to `Attrs`, and multi-parent nodes from repeated rows; deterministic writer ([`2ef27e0`](https://github.com/grokify/taxonomykit/commit/2ef27e0))
- JSON `Document` format (`ParseDocument` strict, `JSON` deterministic) and the `schema` package embedding a JSON Schema generated from the Go types ([`2ef27e0`](https://github.com/grokify/taxonomykit/commit/2ef27e0))
- `taxonomykit` CLI: `validate`, `convert --to csv|tsv|psv|json`, `tree --lang --root --depth`, `lineage --all` ([`b29d441`](https://github.com/grokify/taxonomykit/commit/b29d441))
